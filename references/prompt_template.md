# 提问模板（润色版）

这是本技能的"原始需求"，从一次真实的复现辅导对话中整理而来。用户下次拿到新仓库时，可以直接复制下面的模板，改掉【】里的内容即可；Claude 在理解这套流程的意图时也可以参考它。

---

## 标准版（复制即用）

```text
我是【985 电子信息专业的大二学生】，请你担任【深度学习 + 电磁学】方向的资深讲师，带我复现下面这个 GitHub 仓库。

【项目】
- 仓库地址：【https://github.com/xxx/yyy】
- 本地完整代码：【C:\Users\xxx\Desktop\project\yyy-master】
- 我的环境：【Windows + conda，已装好 PyTorch】；GPU：【有 / 没有 / 不确定】

【步骤】
① 完整、仔细地阅读 README.md（以及仓库里的其他文档和关键源码），理解项目的领域知识和复现方法。
② 思考如何带我复现（结合我的环境），先把你的安排规划写成 md 文档交给我，等我确认后再继续。
③ 亲自把复现流程跑一遍：写好配套的 repro 脚本并测试跑通，记录真实的输出和数值。
④ 从头编写复现指导书 md：
   - 每一步讲清楚原理，结合具体例子，标出注意点和常见坑，给出验收标准；
   - 预期输出要用你实测得到的结果；
   - 最后附上相关的工具资源、学习资源、GitHub 相关仓库、论文（带 DOI）。
⑤ 编写测试验证报告 md：说明你在什么环境下、跑了哪些命令、得到什么结果、发现了哪些问题、哪些部分没能验证。
⑥ 编写任务转接报告 md，记录本次任务和会话的成果，以防下次继续时缺少上下文。

【交付】共四份 md 文档 + 一套 repro 脚本：
  01_复现规划.md、02_复现指导书.md、03_测试验证报告.md（附 my_repro/ 脚本）、04_任务转接报告.md

【要求】讲解尽量详细，标出注意点，结合例子讲解；理论深度【只要会用 / 直觉 + 关键公式 / 推导公式】。
```

## 这套提问逻辑为什么有效（给 Claude 的说明）

| 原始要求 | 背后的意图 | 技能里对应的做法 |
|---|---|---|
| "完整仔细地阅读 README" | 不要只扫一眼就开始写；领域知识和复现方法都藏在文档和代码里 | 阶段 1 深读 + `repo_scan.py` + 文档/代码差异表 |
| "交付思考结果，带我确认后进行下一步" | 学生想掌控方向，避免 Claude 写了一大本不对路的东西 | 阶段 2 交付 01 后**停下**，用选择题确认 |
| "从头书写指导书" | 要的是一本能照着做的教材，不是摘要 | 固定六段式结构、可复制命令、验收标准 |
| "测试报告 / repro scripts" | 指导书里的命令必须真能跑通，结果要有证据 | 阶段 3 先实测，阶段 5 交 03 + 脚本 |
| "转接报告，以防下次缺少上下文" | 复现往往持续好几天、跨多次会话 | 阶段 6 交 04，并存到 Project |
| "工具资源、学习资源、GitHub 仓库、论文 DOI" | 学完之后还能继续往深处走 | 附录 B，DOI 必须核验 |
| "尽量详细、标注意点、结合例子" | 学生基础有限，抽象的解释看不懂 | 数值例子、类比、"现象→原因→解决"的坑点写法 |
